¿Cómo creo mi clave? (una sola vez)
  1. Entra a github.com → crear llave.
  2. Token name: «Panel emi-pao». Expiration: la más larga.
  3. Repository access: «Only select repositories» → emi-pao.
  4. Permissions → Repository → Contents: «Read and write».
  5. Generate token, cópialo y pégalo aquí. Guárdalo en un lugar seguro: es tu clave.
